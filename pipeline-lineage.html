Starset Administration Pipeline Lineage Reporting

National Price Transparency Dataset · V8 → V9
Starset Analytics materializes semantic data layers for Transparency in Coverage negotiated rates — ingesting carrier-payer and hospital-provider machine-readable files into a normalized BigQuery warehouse, then moving them through staged pipeline gates (Lv2 ingestion and analyst filters → post-processing → the PROD national release) for the Starset Pipeline Agents. This report tracks production lineage across those gates by carrier network group (admin_group): Aetna, BCBS, Cigna, Network Plans, and UHC.

Pipeline stages (in sequence).
  1. Lv2_1 Data Ingestion — payer carrier-plan source rate data ingested from machine-readable files.
  2. Lv2_3 Analyst Filters — version tables after applied specialty-taxonomy and place-of-service analyst filters.
  3. Lv2_PP Carrier Processing MMA Code Basket — carrier Lv2 production data transferred for post-processing.
  4. PP_0 Hospital Provider — hospital provider data prepared for post-processing.
  5. PROD National Release MMA Code Basket — production data table from the executed pipeline run.
MMA Code Basket — Lv2_PP and PROD report the MMA client basket, derived from national data: ~3,500 distinct billing codes versus ~8,500 for the national set, which is why median distinct codes normalize downward at these stages.

All five admin groups report in both versions across stages. At Lv2_1 and Lv2_3, Aetna’s v9 applies its v8 data by release decision (zero v8→v9 delta at those stages); at the downstream stages (Lv2_PP, PP_0, PROD) Aetna reports a native v9. At PROD, Network Plans reports v9 only (no v8 production records), so the PROD Total Δ compares the four groups present in both versions. Bars share a common scale so groups and stages are directly comparable.

Lv2_PP and PROD report the MMA client basket and are labeled MMA v8 / MMA v9, mapped onto the v8 / v9 comparison axis; Lv2_1, Lv2_3, and PP_0 are National. PROD reflects production records where npi_include = 1. PP_0 (hospital provider) carries a third billing class, not designated, reported by hospitals. Counts are raw record rows at each stage.
