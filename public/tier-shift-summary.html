Tier Shift Summary by MSA — V8 to V9

Change in green + yellow share (pp) across up to 977 MSAs, by carrier plan name, billing class, and billing code type

What this shows. This dashboard compares reimbursement rate confidence tier distributions between dataset versions V8 and V9, across up to 977 Metropolitan Statistical Areas (MSAs). Each billing code in the dataset is classified into one of three confidence tiers — green (highest confidence), yellow (moderate), or red (lowest confidence) — based on the adequacy of the underlying rate data. The metric shown is the change in the combined green + yellow share (Δ G+Y) in percentage points: a positive value means more codes moved into green or yellow in V9 relative to V8; a negative value means codes shifted toward red. Because green + yellow + red must sum to 100%, Δ G+Y and Δ red are always equal and opposite.
How to read the cards. Results are organized by carrier plan, then broken out by billing class (Institutional / Professional) and billing code type (CPT, HCPCS, MS-DRG). Each combination shows the average Δ G+Y across MSAs, a box plot of the distribution (median, interquartile range, and whiskers to min/max), and a count bar showing how many MSAs improved versus worsened. Use the filters at the top to narrow by billing class, code type, or overall trend direction, and search by plan name to jump to a specific carrier.
Notes. MSA counts per combo vary by carrier — national plans cover up to 977 MSAs; regional plans cover only the markets where they operate. MSAs where both V8 and V9 had no codes in a given combination are excluded. The 48 non-standard codes (99001–99048) represent custom non-MSA regional groupings in the source data.
